# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, leaked credentials, or sensitive repository details in
a public issue.

After the GitHub repository is created, use its private vulnerability reporting or Security
Advisory feature. Include affected versions, reproduction steps, impact, and any proposed fix.

## Credential policy

Credentials must never be committed to the repository or bundled into the VSIX. Registry tokens
belong in protected repository secrets and should be scoped to the minimum required permissions.
